# Tacit Collusion and Oversight Evasion in Multi-agent Environments

The following repo contains the code for the apart submission "Tacit Collusion and Oversight Evasion in Multi-agent Environments"

Inspect AI was used to facillitate the experiments. 

The game implementation of the games comes from the [repository](https://github.com/Jerick-1380/LLM-Trust-Breaking) for the paper "When Agents Lie: Premeditation, Persistence, and Exploitation in Repeated Games" by [Shi et al](https://arxiv.org/html/2607.05132v2).


To run an experiment run the experiment script in `experiment.py` using python. 
```bash
python experiment.py
```
